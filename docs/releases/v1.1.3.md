## 更新内容

- Linux 和 Windows 新增菜单栏自动隐藏开关，默认保持显示。在 **View → Auto-hide Menu Bar (Alt to Show)** 中开启，单按 **Alt** 可临时显示，**Ctrl+Shift+M** 可切换；重启后记住设置。
- 修改更新检查设置时保留菜单栏隐藏偏好；macOS 继续使用系统菜单。
- Electron 更新至 **44.7.2**，electron-builder 更新至 **26.17.0**，整合 #13 和 #9 的依赖更新。
- 修复干净安装所需的依赖锁文件，并更新存在高危问题的间接构建依赖 http-cache-semantics 至 **4.3.0**。

感谢 [@ChRomiumCR](https://github.com/ChRomiumCR) 提出需求，并在 **Linux Mint 22.3 / Cinnamon 6.9 / X11** 下测试 deb 和 AppImage 候选版本，帮助确认修复有效（[#12](https://github.com/NeilYXIN/WeRead_Desktop/issues/12)）。

## What's changed

- Added optional menu bar auto-hide on Linux and Windows. Enable **View → Auto-hide Menu Bar (Alt to Show)**, press **Alt** to reveal it temporarily, or **Ctrl+Shift+M** to toggle. The menu stays visible by default and the preference persists across restarts.
- Preserved menu bar preferences when update settings rebuild the menu; macOS retains its system menu.
- Updated Electron to **44.7.2** and electron-builder to **26.17.0**, incorporating the updates proposed in #13 and #9.
- Repaired the dependency lockfile for clean installs and updated the vulnerable transitive build dependency http-cache-semantics to **4.3.0**.

Thanks to [@ChRomiumCR](https://github.com/ChRomiumCR) for requesting this feature and verifying both deb and AppImage candidates on **Linux Mint 22.3 / Cinnamon 6.9 / X11** ([#12](https://github.com/NeilYXIN/WeRead_Desktop/issues/12)).

## Downloads / 下载说明

- macOS: choose arm64 for Apple Silicon or x64 for Intel.
- Windows: use the x64 installer.
- Linux: choose the x86_64 AppImage or amd64 deb package.
- Files ending in `-unsigned` are unsigned. SHA-256 checksums and signing-status notes are included.

macOS 根据芯片选择 arm64 或 x64；Windows 使用 x64 安装程序；Linux 可选择 x86_64 AppImage 或 amd64 deb。文件名以 `-unsigned` 结尾的安装包未签名，下载文件附有 SHA-256 校验值和签名状态说明。
